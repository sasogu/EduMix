# Test plan: EduMix

## Scope
- In scope: static PWA shell, JavaScript module syntax/importability, service worker/version consistency, manifest/icons, core pure helpers, and recent 1.7.6 claims around playlist deletion sync markers, dialog maxLength, and Dropbox folder 409 handling by code inspection.
- Out of scope: real Dropbox/WebDAV writes, audio playback in a real browser, IndexedDB persistence with real files, mobile background controls, and production deployment.

## Claims and scenarios

### C1 — The app shell is servable as a static PWA
- Risk if broken: users get a blank page, missing assets, or install/offline breakage.
- Scenario: serve project locally and fetch `/`, core JS/CSS/assets, manifest and service worker.
- Setup/data: local static HTTP server.
- Oracle / expected result: HTTP 200 for shell assets; manifest JSON parses and referenced icons exist.
- Evidence to collect: curl status codes, manifest validation script.
- Method: HTTP + file inspection.

### C2 — JavaScript modules are syntactically valid
- Risk if broken: app fails immediately in browser.
- Scenario: run `node --check` on `app.js`, service worker, version file and all modules.
- Setup/data: local checkout.
- Oracle / expected result: no syntax errors.
- Evidence to collect: command output.
- Method: syntax check.

### C3 — Core pure helpers preserve playlist/track invariants
- Risk if broken: duplicates, cleanup, or remote deletion logic corrupts user libraries.
- Scenario: import pure helper modules in Node and test duplicate detection and reference counting.
- Setup/data: synthetic playlists/tracks.
- Oracle / expected result: auto playlists ignored; duplicate criteria work; reference counts exclude selected playlists and ignore auto lists.
- Evidence to collect: Node test output.
- Method: targeted unit smoke.

### C4 — Deleting a playlist leaves cloud-sync tombstones for list deletion
- Risk if broken: deleted cloud playlists reappear on other devices.
- Scenario: inspect `deleteActivePlaylist` and recent code path.
- Setup/data: code inspection of `modules/playlist-crud.js` and sync metadata hooks.
- Oracle / expected result: deletion records the playlist id, queues per-list remote path deletion, removes per-list metadata, persists local playlist and requests sync.
- Evidence to collect: line references / grep output.
- Method: code inspection.

### C5 — App dialog prompt enforces maxLength consistently
- Risk if broken: browser ignores intended length limit or stale `maxlength` leaks into non-prompt dialogs.
- Scenario: inspect dialog prompt path.
- Setup/data: code inspection of `modules/app-dialog.js`.
- Oracle / expected result: prompt sets `inputEl.maxLength = inputMaxLength || 200`; non-prompt removes `maxlength`.
- Evidence to collect: line references / grep output.
- Method: code inspection.

### C6 — Dropbox create-folder conflict avoids harmful 409 handling
- Risk if broken: sync reports false errors or fails repeatedly when `/Playlists` already exists.
- Scenario: inspect Dropbox folder/create conflict handling around 409s.
- Setup/data: code inspection of `modules/dropbox-sync.js`.
- Oracle / expected result: create-folder conflict is handled/ignored where appropriate; playlist saves continue.
- Evidence to collect: grep output around 409/create_folder/conflict.
- Method: code inspection.

### C7 — Release metadata is coherent
- Risk if broken: service worker cache points at wrong version; users stay on stale assets.
- Scenario: inspect `version.js`, service worker APP_VERSION and footer/version usage.
- Setup/data: local checkout at latest commit.
- Oracle / expected result: `version.js` exposes 1.7.6; service worker imports it and falls back safely.
- Evidence to collect: grep output.
- Method: code inspection.

## Coverage note
- What this plan gives confidence in: EduMix can load as a static app, its JS parses, key helper logic behaves under synthetic data, and the latest fix claims are present in code.
- What remains untested: real browser playback, real Dropbox/WebDAV credentials and network sync, mobile/PWA install behavior, IndexedDB storage under quota pressure, and service worker update behavior across an already-installed client.
